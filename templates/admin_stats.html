사이트 공지 배너

켜 두면 사이트 모든 페이지 맨 위에 띠 모양 공지가 떠요. 방문자가 닫으면 같은 공지는 다시 안 뜨고, 내용을 바꾸면 다시 떠요.

공지 미리보기

선택한 색상과 내용이 즉시 반영됩니다. 긴 공지는 줄바꿈됩니다.

점검 모드

켜면 관리자가 아닌 방문자는 모든 페이지에서 "지금은 점검 중이에요" 화면을 봐요. 관리자는 평소처럼 사이트를 쓸 수 있고, 로그인·관리자 화면은 막히지 않아요.

금지어

여기 있는 단어가 들어간 댓글, 커뮤니티 글, 팬아트 제목·설명, 닉네임은 올라가지 않아요. 띄어쓰기와 대소문자는 무시하고 찾아요.

대화 생성 설정

현재 PC에 설치된 모델을 선택하세요.

답변 다양성은 0~1, 기억 참고 범위는 0~12회입니다. 전체 정상 대화는 파일에 계속 저장됩니다.
